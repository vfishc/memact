# Upstream assets (not bundled)

Obtain upstream data from its original provider, following the provider's access and license requirements:

- ScanNet: https://www.scan-net.org/ScanNet/
- ScanNet++: https://scannetpp.mlsg.cit.tum.de/scannetpp/ and https://github.com/scannetpp/scannetpp
- ARKitScenes: https://github.com/apple/ARKitScenes (see DATA.md and LICENSE).
- 3D-FRONT/3D-FUTURE: https://tianchi.aliyun.com/specials/promotion/alibaba-3d-scene-dataset and https://github.com/3D-FRONT-FUTURE/3D-FUTURE-ToolBox

The dataset code and source data may have different licenses. Generated annotations, videos, textures and meshes are not automatically covered by one blanket code license. No raw upstream download, access token, model weight or authentication file is included here. Public download/reconstruction recipes must use source IDs and relative paths rather than the internal locator files created during the audit.
